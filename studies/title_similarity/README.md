# 相近措辞的标题对

这项对照只使用课程标题训练文件。问题是：同一对标题用词高度重合时，能否改进混合模型的排序，同时保持其余标题对的预测完全一致？

## 两条路线

- **共享权重加分组权重**（`domain_features`）。在原词、字符和写作风格差值之外，增加两组按相似性激活的特征，让模型学习共同规律与各组的偏差。预测时只在相近组使用这个模型。这里将 Daumé 的特征扩展法用于同一数据集的两个子组。[原始论文](https://aclanthology.org/P07-1033/)
- **归一化词面改动**（`unit_lexical_edit`）。两侧 TF-IDF 相减后，再把非零差向量缩放到单位长度，保留原有写作风格特征。这样可以检验基线是否低估了少量改词的影响。[scikit-learn 的归一化定义](https://scikit-learn.org/stable/modules/generated/sklearn.preprocessing.Normalizer.html)

两条路线继承相同训练折拟合的词表、写作风格缩放器和逻辑回归配置。相似性的定义与 Agent 的训练诊断一致：两侧分别按空白分词并折叠大小写，词集合交集占并集比例至少为 0.65。其他标题对沿用基线，包括每个类别的预测概率。

## 首轮结果

| 方法 | 相近组答对 / 541 | 全部答对 / 6,225 | 与基线相比纠正 / 新错 | 各折答对数变化 |
| --- | ---: | ---: | ---: | --- |
| 原混合模型 | 303 | 4,136 | — | — |
| 共享权重加分组权重 | 313 | 4,146 | 79 / 69 | −2、+5、+8、−1 |
| 归一化词面改动 | 293 | 4,126 | 16 / 26 | −1、−7、−3、+1 |

原定晋级条件为总体准确率提高至少 0.5 个百分点且赢至少三折。在这个样本量下，前一条件需要净增至少 32 条。专用权重净增 10 条（+0.16 个百分点），相近组提高 1.85 个百分点。按相近组内的连通标题组重采样 5,000 次，后者的描述性 95% 区间为 −2.68 至 +6.54 个百分点。它描述这一组折外预测的波动，不能替代新数据评估。两种候选均未晋级，因此本轮没有在 2,076 条训练确认样本上评分，也没有打开课程验证或测试文件。

首轮决定锁定后，对唯一有正收益的候选做了一次诊断性复核：仍用这 6,225 对，按同一连通组规则、更换随机种子为 7919。相近组从 308/541 提高到 321/541，总体从 4,155/6,225 提高到 4,168/6,225（+0.21 个百分点），各折净变化为 +6、−6、+10、+3。两次划分都出现小幅收益，也都低于总体门槛。这次复用的是相同样本，不能将两次结果合并计算样本量。专用权重可留作候选，当前交付继续使用原混合模型。

首轮基线的 2,089 条错误中，1,851 条来自措辞差异较大的标题对。此前的混合模型、词项对比模型和纯 TF-IDF 在其中 1,421 条上同时出错。这部分样本能帮助定位现有词面表示共同遗漏的信息。

## 复核

按仓库 README 安装依赖。先用当前 Agent 的课程训练入口得到 `runs/final/headline`，已有对应训练目录可直接使用。下列命令自行核对原始训练分组，记录 ZIP 文件读取，保留每一折的模型和折外概率，并检验模型重载及 A/B 互换的一致性。第二条命令只在原排名分区换分组复核首轮唯一有正收益的候选，不能改变首轮决定。

~~~powershell
& $py studies/title_similarity/run.py --data $archive --frozen runs/final/headline --out runs/similar-titles
& $py studies/title_similarity/repeat.py --data $archive --frozen runs/final/headline --first runs/similar-titles --out runs/similar-titles/repeat
~~~
